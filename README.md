# onIT — IT Ticketing System

> Fast IT support and ticket tracking for **UC-METC Multipurpose Cooperative**.

A lightweight, modern IT ticketing system built with **Pure Python (Standard Library)** and **SQLite 3**, requiring **zero external dependencies**.

---

## ⚡ Features

- **Operations Console**: Kanban board and master data table with instant triage.
- **Management Portal**: Issue requests, monitor progress, and review resolutions.
- **Activity Timeline**: Complete history with developer updates and private internal notes.
- **Settings & Preferences**: Live profile updates, username & password management, and notification controls.
- **Zero Dependencies**: Runs out of the box on Python 3.10+ without `pip install`.

---

## 🚀 Quick Start

### Windows
Double-click [`run.bat`](run.bat) or run:

```bash
python app.py
```

Open your browser to: **http://127.0.0.1:5000/**
